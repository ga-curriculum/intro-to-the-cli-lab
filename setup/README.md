# Intro to the CLI Lab - Setup

![Hero image](./assets/hero.png)

## Setup

This Lab only requires the use of your system's Command Line Interface (CLI).

1) Open the **Terminal app**

2) Navigate to your **`~/code/ga/labs`** directory:

```bash
cd ~/code/ga/labs
```

3) Make a new directory called **`star_wars`**, then enter this directory:

```bash
mkdir star_wars
cd star_wars
```


**Complete all work using the CLI inside the `star_wars` directory.**
